# Prove d'Esame 

Questa cartella raccoglie le tracce e le relative soluzioni delle prove d'esame passate (e relative simulazioni) svolte in preparazione all'esame.

## Organizzazione dei file

Per ogni appello d'esame sono presenti tipicamente due file associati:
- 📄 **File `.txt`**: Contiene il testo originale dell'esame e le specifiche richieste per l'implementazione.
- ☕ **File `.java`**: Contiene il codice sorgente con la soluzione svolta e commentata.

## Consigli per lo studio

Si consiglia di aprire prima il file di testo contenente la traccia (`.txt`), tentare di implementare la struttura dati o l'algoritmo richiesto in autonomia, e solo in un secondo momento consultare il file `.java` per confrontare il proprio codice con la soluzione proposta.
