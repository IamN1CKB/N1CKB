# Algoritmi e Strutture Dati (Java)

Questa cartella contiene implementazioni in Java di vari algoritmi e strutture dati, oltre a esercizi e soluzioni a prove d'esame. Il repository è organizzato in diverse sezioni per facilitare lo studio e la consultazione del codice.

## Struttura della directory

Come visibile dall'alberatura del progetto (riferimento a `image_3fbfaf.png`), la cartella è divisa nei seguenti moduli:

*   📂 **`Esercitazione_strutture_dati/`**
    Contiene esercizi pratici per testare e consolidare l'utilizzo delle principali strutture dati.
*   📂 **`Prove_d_esame/`**
    Raccolta di tracce d'esame passate e relative soluzioni (es. prove di Marzo 2026). Include implementazioni specifiche richieste dai testi d'esame.
*   📂 **`Strutture_dati/`**
    Implementazioni classiche delle strutture dati fondamentali (Liste, Code, Alberi, Grafi, ecc.) sviluppate in Java.
*   📂 **`algoritmi_ordinamento/`**
    Implementazioni dei principali algoritmi di ordinamento (Sorting algorithms) e studio della loro complessità.
*   📂 **`interfacce_non_usate/`**
    Contiene interfacce, classi base modificate (come `DoublyLinkedList` con visibilità `protected`) o versioni alternative del codice mantenute per scopi didattici o di ereditarietà specifica.

## Requisiti e Utilizzo

Tutto il codice è scritto in **Java**. Per compilare ed eseguire i file è necessario avere installato il [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/).

Puoi compilare un singolo file da riga di comando utilizzando:
```bash
javac NomeFile.java
```
Ed eseguirlo con:
```bash
java NomeFile
```
