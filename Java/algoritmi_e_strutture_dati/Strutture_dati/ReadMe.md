# Strutture Dati

Questa cartella contiene tutte le **interfacce** e le **implementazioni** delle strutture dati fondamentali utilizzate per lo svolgimento degli esercizi e delle prove d'esame.

## ⚠️ Note e Limitazioni

Sono state volutamente escluse da questa directory alcune strutture dati la cui implementazione "perfetta" o perfettamente integrata nel linguaggio risulta complessa per gli scopi attuali:

* **ArrayList**: Esclusa a causa delle dinamiche complesse legate all'autodimensionamento della struttura (*resizing*).
* **Iteratori**: L'interfaccia personalizzata è esclusa per via delle limitazioni nell'integrazione diretta con il costrutto nativo *for-each* di Java.

💡 **Dove trovarle?** Le versioni studiate e le implementazioni a scopo puramente didattico di queste strutture escluse sono consultabili nell'apposita cartella `interfacce_non_usate`.
