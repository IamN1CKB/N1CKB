In questa cartella trovi tutte le inferfacce e implementazioni delle strutture dati che usiamo negli esercizi e 
nelle prove d'esame. Sono escluse alcune strutture dati che non riusciamo a implementare perfettamente come 
l'ArrayList (a causa dell'autodimensionamento) e l'interfaccia degli iteratori (a causa del for each loop), 
le cui implementazioni studiate sono nella cartella "interfacce_non_usate".
