Scorciatoie per Windows

Combinazioni utili per gestire il desktop, il sistema e le applicazioni.

Windows + D

Mostra il desktop nascondendo tutte le finestre aperte. Premila di nuovo per ripristinarle.

Windows + V

Apre la cronologia degli appunti per recuperare gli ultimi elementi copiati.

Windows + V

Dal pannello degli appunti puoi anche accedere a simboli ed emoji non presenti direttamente sulla tastiera.

Shift + Ctrl + Windows + B

Reimposta i driver video quando lo schermo si blocca o smette di rispondere. Lo schermo potrebbe lampeggiare brevemente.

Ctrl + Shift + Esc

Apre direttamente Gestione attività, utile per terminare le applicazioni che non rispondono.

Ctrl + Alt + Canc

Apre il menu di sicurezza di Windows con opzioni per bloccare, cambiare utente o aprire Gestione attività.

Windows + Shift + S

Avvia lo strumento Cattura e ritaglia per fare uno screenshot di una parte dello schermo.

Windows + I

Apre rapidamente le Impostazioni di Windows.

Windows + G

Apre Xbox Game Bar, con strumenti per registrare lo schermo e controllare le prestazioni.

Windows + R, poi mrt

Apre lo strumento di rimozione malware di Microsoft per avviare una scansione del computer.

Nota: per il comando Windows + R prima apri la finestra Esegui, digita mrt e premi Invio.

Scorciatoie per Visual Studio Code

Comandi per modificare il codice e gestire più cursori.

Ctrl + /

Trasforma una riga di codice in un commento.

Alt + Shift + ↑ o ↓

Duplica una riga di codice sopra o sotto quella corrente.

Ctrl + C / Ctrl + V

Copia e incolla la riga su cui si trova il cursore anche senza selezionarla.

Ctrl + Shift + L

Seleziona tutte le parole corrispondenti a quella selezionata.

Ctrl + Shift + K

Rimuove la riga di codice corrente.

Rotellina premuta + trascinamento

Seleziona il testo in forma rettangolare.

Ctrl + D

Seleziona la corrispondenza successiva e permette di modificarle tutte insieme.

Alt + Z

Attiva o disattiva il ritorno a capo automatico.

Alt + W

Con l'estensione HTMLTagWrap, racchiude il codice selezionato in un tag.

Cursori multipli

Alt + clic

Aggiunge cursori in più punti del file.

Rotellina premuta + trascinamento verticale

Crea più punti in cui scrivere contemporaneamente.

Ctrl + Alt + ↑ o ↓

Aggiunge un cursore sopra o sotto quello corrente.

Ctrl + U

Annulla l'ultimo cursore aggiunto.

Codici ASCII utili

Puoi consultare l'elenco completo dei codici qui.

  • Alt + 96 → `
    Il carattere backtick.
  • Alt + 158 → ×
    Il simbolo di moltiplicazione.

Altri consigli

Piccoli trucchi utili nella scrittura quotidiana.

  • Shift + Invio
    In un campo di testo, ad esempio WhatsApp, Telegram o ChatGPT, va a capo senza inviare il messaggio.
